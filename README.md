## Elektronisches Dienstbuch · Wache TOR B

Eine responsive Demo-Anwendung für die Wache TOR B am VW Motorenwerk Chemnitz. `index.html` direkt im Browser öffnen oder über einen statischen Webserver bereitstellen.

### Demo-Zugänge

| Rolle | Benutzername | Passwort |
| --- | --- | --- |
| Schichtführer | `richter` | `torb2026` |
| Wachpersonal | `weber` | `torb2026` |
| Administrator | `admin` | `admin2026` |

### Funktionen

- Rollenbasierte Demo-Anmeldung und Benutzerverwaltung
- Vorfälle, Besucher, Schlüsselübergaben und Schichtprotokolle erfassen
- Statusaktionen, Suche, Filter und Lageübersicht
- Berichte aller Eintragstypen drucken bzw. über den Browser als PDF speichern
- Beispieldaten und Änderungen bleiben im jeweiligen Browser via `localStorage` erhalten

**Hinweis:** Diese eigenständige Demo nutzt Browser-Speicher anstelle eines zentralen Backends. Zugangsdaten und Rollenprüfung sind nicht produktionssicher. Für den realen Einsatz sind ein abgesichertes Backend, serverseitige Autorisierung, zentrale Benutzerverwaltung, Zugriffskontrolle, Protokollierung und Datenschutz-/Betriebsratsprüfung erforderlich. Keine realen Sicherheits- oder Personendaten in dieser Demo speichern.
